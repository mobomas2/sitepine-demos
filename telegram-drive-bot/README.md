# ربات تلگرام → گوگل درایو → Muse  (نسخهٔ ۲.۰ — کاملاً خودکار)

همه‌چیز در یک فایل: **`Code.gs`**. هیچ سرور، هیچ Colab، هیچ Google Cloud Console لازم نیست.

## چه کار می‌کند

| کاری که تو می‌کنی | کاری که ربات می‌کند |
| --- | --- |
| لینک ریل/پست اینستاگرام را برای ربات می‌فرستی | خودش دانلود می‌کند → در درایو (پوشهٔ تاریخ) ذخیره می‌کند → لینک درایو را می‌دهد → خودکار به Muse می‌فرستد |
| فایل/عکس/ویدیو/متن می‌فرستی | ذخیره می‌کند + لینک + ارسال خودکار به Muse |
| فایل آماده را از ربات دانلودر (`@SaveThat4Me` و مشابه) فوروارد می‌کنی | همان مسیر بالا |

بعد از هر ذخیره، دکمهٔ **🤖 ارسال به Muse** هم زیر پیام می‌آید (لینک درایو + نام فایل آماده در واتساپ).

## نصب (۳ دقیقه)

1. کل `Code.gs` را در [script.new](https://script.new) پیست کن.
2. `Ctrl+S`.
3. از منوی توابع `START` را انتخاب و Run کن (یک‌بار). دسترسی‌ها را Allow کن.
4. تمام. از این به بعد تریگر هر ۱ دقیقه خودش `POLL` را اجرا می‌کند.

`START` تست می‌کند: توکن، دسترسی درایو، حذف webhook، نصب تریگر.

## تنظیمات بالای فایل

```js
var BOT_TOKEN = '…';        // توکن @BotFather (سه تکه نوشته شده تا گیت‌هاب آن را نگیرد)
var FOLDER_ID = '';         // خالی = ریشهٔ My Drive
var BY_DATE   = true;       // زیرپوشهٔ 2026-11-03
var MAX_MB    = 19;         // سقف دانلود Bot API
var ALLOWED   = [83885823]; // فقط تو

var IG_ON   = true;         // بخش اینستاگرام
var IG_APIS = [ … ];        // نمونه‌های عمومی cobalt (اگر یکی جواب نداد، بعدی)

var MUSE_WA      = '';      // شمارهٔ واتساپ ایجنت Muse (بدون +). خالی = خود واتساپ چت را می‌پرسد
var MUSE_EMAIL   = '';      // ایمیل Muse → خودکار برایش می‌فرستد
var MUSE_WEBHOOK = '';      // وبهوک (JSON با text/url/title) — مثلاً گیت‌وی واتساپ
var MUSE_AUTO    = true;    // ارسال خودکار بعد از هر ذخیره
```

- برای **ارسال خودکار** به Muse: `MUSE_EMAIL` (اگر ایجنت Muse ایمیل قبول می‌کند) یا `MUSE_WEBHOOK`.
- اگر هیچ‌کدام خالی بماند، فقط دکمهٔ دستی می‌ماند.

## دستورها

| دستور | کار |
| --- | --- |
| `/start` | راهنما |
| `/id` | آیدی عددی (برای `ALLOWED`) |
| `/folder` | لینک پوشهٔ مقصد |
| `/igtest <لینک ریل>` | همهٔ نمونه‌های cobalt را تست می‌کند و می‌گوید کدام زنده است |
| `/ig <لینک>` | دانلود دستی همان لینک |
| `/muse` | ارسال دوبارهٔ آخرین فایل به Muse |
| `/ping` | تست زنده بودن |

## محدودیت‌ها (بدان که غافلگیر نشوی)

- **Bot API سقف دانلود ۲۰ مگابایت** دارد (`MAX_MB = 19`). ریل‌های بزرگ‌تر پیام خطا می‌گیرند. در مسیر اینستاگرام، کیفیت ۷۲۰ درخواست می‌شود که معمولاً زیر این سقف است.
- نمونه‌های cobalt **عمومی و داوطلبانه** هستند؛ ممکن است خاموش شوند یا محدودیت نرخ بدهند. ربات همه را امتحان می‌کند و اولی که جواب داد را می‌گیرد. با `/igtest` ببین کدام زنده است و همان را اول `IG_APIS` بگذار.
- Apps Script: ۶ دقیقه به‌ازای هر اجرا، ۹۰ دقیقه در روز، ۲۰٬۰۰۰ فراخوانی بیرونی در روز، ۲۵۰ سند گوگل در روز.
- تأخیر polling حدود ۱ دقیقه است (حداکثر ۲۰ پیام در هر اجرا).
- اگر همهٔ نمونه‌ها خواب بودند: فایل را از ربات دانلودر در تلگرام بگیر و به همین ربات فوروارد کن.

## تست

تست‌های خودکار (mock کامل `DriveApp` / `UrlFetchApp` / `DocumentApp` / `MailApp`) روی این نسخه: **۴۸ تست، همه سبز** — شامل مسیر اینستاگرام (موفق، fallback نمونه‌ها، شکست کامل، آلبوم/کاروسل، فایل بزرگ) و ارسال خودکار Muse (وبهوک و ایمیل).

## جایگزین بدون نمونهٔ عمومی

اگر نمونهٔ قابل‌اتکا خواستی: یک نمونهٔ cobalt خودت را روی Railway/Fly با Docker بالا بیار و آدرسش را اول `IG_APIS` بگذار. یا یک ورکر کوچک با `yt-dlp` روی سرور/رزبری‌پای که فایل را به درایو بفرستد.
