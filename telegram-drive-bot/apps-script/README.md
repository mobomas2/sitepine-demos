# 🅖 مسیر بدون Cloud Console: Google Apps Script

اگر در Google Cloud Console بن شده‌ای (`Multiple Google services … unavailable`)، راه OAuth / Service Account بسته است. اما **Apps Script** یک راه کاملاً متفاوت است:

| | مسیر پایتون (`bot.py`) | ✅ مسیر Apps Script |
|---|---|---|
| Google Cloud Console | لازم است (بن شده‌ای → ❌) | **لازم نیست** |
| OAuth client / refresh token | لازم است | **لازم نیست** |
| سرور / VPS / Docker | لازم است | **لازم نیست** |
| هزینه | سرور | **رایگان** |
| محدودیت | — | سهمیه روزانه Apps Script (پایین توضیح داده شده) |

اسکریپت داخل خود گوگل اجرا می‌شود، با اجازه‌ی همان اکانتی که لاگین هستی، فایل را از تلگرام می‌گیرد و در درایو می‌گذارد.

> **دو نسخه از همان کد:** [`Code.template.gs`](Code.ascii.gs) (کاملاً ASCII، برای paste بی‌دردسر) و [`Code.gs`](Code.gs) (با کامنت فارسی).
> اگر خطای `SyntaxError` گرفتی، نسخه ASCII را بچسبان — هر دو با ۱۲ تست یکسان تست شده‌اند.

## 🔴 اول از همه: توکن ربات را عوض کن

توکنی که فرستادی (`8621978100:AAH...`) **لو رفته** است (در چت عمومی نوشته شد). هر کسی با آن می‌تواند جای تو ربات را کنترل کند.

1. در تلگرام به **@BotFather** برو
2. `/mybots` → `@T2GD2Tbot` → **API Token** → **Revoke current token**
3. توکن جدید را فقط در Apps Script بگذار (مرحله ۳ پایین) — نه در چت، نه در گیت‌هاب

> اگر قبلاً کسی با آن توکن webhook ست کرده باشد، با همین `action=setup` پایین بازنویسی می‌شود.

## 🥇 یک فایل، سه کلیک — `Code.single.gs`

**کل پروژه در یک فایل است.** در Apps Script هر پروژه = چند فایل `.gs`؛ این فایل **همه‌چیز** را دارد (توکن، حلقهٔ دریافت پیام، آپلود به درایو، آلبوم، دستورها، گزارش وضعیت). پس نیازی به فایل دوم، دیپلوی، Web app، لینک یا سکرت نیست.

> ⚠️ صادقانه: Apps Script دکمهٔ «Import فایل» از درایو **ندارد** (نه برای `.gs`، نه `.zip`). تنها راه رسمی، چسباندن محتوا در ادیتور است. خبر خوب: همین ۳ کلیک کافی است و دست به هیچ کدی نمی‌زنی.

### مراحل

1. برو به <https://script.google.com> → **New project** (اگر پروژهٔ قبلی داری، همان را باز کن).
2. در ادیتور **Ctrl+A** → **Delete** → محتوای **`Code.single.gs`** را کامل بچسبان → **Ctrl+S**.
3. از منوی کشویی توابع بالای صفحه **`START`** را انتخاب کن → **Run** → یک‌بار **Allow** کن.

در **Execution log** این را می‌بینی:

```
=== راه‌اندازی ربات تلگرام → گوگل درایو ===
نسخه: single-1.0
۱) تست توکن...
   ✅ ربات: @T2GD2Tbot
۲) بررسی دسترسی به گوگل درایو...
   ✅ پوشه مقصد: My Drive
۳) حذف webhook (لازم برای حالت polling)...
   {"ok":true,...}
۴) نصب تریگر هر ۱ دقیقه...
   ✅ تریگر نصب شد (تعداد: 1)
۵) پردازش پیام‌های معلق...
   ✅ N پیام پردازش شد

🎉 تمام شد. همین حالا در تلگرام به ربات پیام بده.
```

**تمام.** هر چیزی به ربات بفرستی، حداکثر ۱ دقیقه بعد در `My Drive` (پوشهٔ تاریخ امروز) ذخیره می‌شود.

### چهار تابع همین فایل

| تابع | کار |
|---|---|
| `START` | راه‌اندازی کامل: تست توکن، نصب تریگر ۱ دقیقه‌ای، پردازش معلق‌ها (فقط یک‌بار) |
| `POLL` | یک دور فوری (برای جواب سریع بدون منتظر دقیقه) |
| `STATUS` | گزارش: توکن، پوشه، تریگر، offset، وضعیت webhook، آخرین آپدیت |
| `STOP` | خاموش کردن کامل ربات |

### تنظیمات داخل همان فایل (بالای فایل)

```js
var FOLDER_ID = '';      // آیدی پوشه مقصد؛ خالی = ریشهٔ درایو
var BY_DATE   = true;    // زیرپوشهٔ تاریخ‌دار
var TEXT_MODE = 'doc';   // 'doc' = سند گوگل | 'txt' = فایل متنی
var MAX_MB    = 19;      // سقف حجم هر فایل
var ALLOWED   = [];      // مثلاً [123456789] تا فقط خودت بتوانی آپلود کنی
var TIMEZONE  = 'Asia/Tehran';
```

تست‌ها (روی همین ماشین، چون فایل‌های شخصی در گیت نیستند):

```bash
node apps-script/test_single.js    # 14/14  ← نسخه‌ی Code.single.gs
node apps-script/test_minimal.js   #  5/5   ← نسخه‌ی Code.minimal.gs
node apps-script/test_local.js     # 41/41  ← نسخه‌ی Code.template.gs
```

اگر فایل شخصی پاک/بازسازی شد:

```bash
python apps-script/make_personal.py '8621978100:...' --secret tgdrive2026
```

2. در ادیتور Apps Script: **Ctrl+A → Delete → Ctrl+V** (کل فایل) → **Ctrl+S**.
3. از منوی کشویی توابعِ بالای صفحه، **`RUN_ME_ONCE`** را انتخاب کن → **Run** → یک‌بار **Allow** کن.
4. در **Execution log** باید این را ببینی:

   ```
   ✅ تمام شد. حالا در تلگرام به ربات پیام بده.
   ```
5. تمام. در تلگرام به ربات پیام بده؛ حداکثر ۱ دقیقه بعد جواب می‌دهد.

**ساختن دوبارهٔ همین نسخه با توکن دیگر:**

## 🚀 راه‌اندازی دستی در ۶ مرحله (حدود ۵ دقیقه)

### ۱. پروژه بساز

برو به **<https://script.google.com>** → **New project** (با همان اکانت گوگلی که درایو دارد).

### ۲. کد را بگذار

اول **همه چیز** را در ادیتور انتخاب کن (Ctrl+A) و **پاک کن** (Delete)، بعد یکی از این دو فایل را کامل بچسبان:

| فایل | چه وقت |
|---|---|
| [`Code.template.gs`](Code.ascii.gs) | ✅ **پیشنهادی** — کاملاً ASCII؛ اگر خطای `SyntaxError` گرفتی از این استفاده کن (فارسی‌ها به `\uXXXX` تبدیل شده‌اند، خروجی ربات همچنان فارسی است) |
| [`Code.gs`](Code.gs) | همان کد با کامنت‌های فارسی (خوش‌خوان‌تر) |

بعد Ctrl+S بزن. اسم پروژه را مثلاً `Telegram→Drive` بگذار.

**چک سریع:** خط اول باید `/**` باشد و خط آخر `}`. اگر خط اول چیزی مثل `[Code.gs](...)` یا متن دیگری بود، پاکش کن.

### ۳. توکن را جای‌گذاری کن (مهم‌ترین قدم)

اسکریپت از تو «نمی‌پرسد»؛ جای توکن **داخل خود کد** است. بالای فایل، این خط را پیدا کن (در `Code.template.gs` حدود **خط ۳۹**، در `Code.gs` حدود **خط ۲۳**):

```js
  BOT_TOKEN: 'PUT-YOUR-NEW-BOT-TOKEN-HERE',
```

فقط متن بین دو کوتیشن را با توکن **جدید** عوض کن:

```js
  BOT_TOKEN: '8621978100:AAH...',
```

⚠️ نکته‌ها:
- کوتیشن‌ها (`' '`) را نگه دار، فاصله اضافه نگذار.
- توکن را از @BotFather گرفته باشی و **Revoke**شده نباشد.
- بعد از تغییر، **Ctrl+S** بزن.

**راه دوم (اگر نمی‌خواهی توکن داخل کد باشد):** ⚙️ Project Settings → **Script Properties** → **Add property** → Name: `BOT_TOKEN` ، Value: توکن. (کد اول `CONFIG` را می‌خواند و اگر آنجا مقدار نمونه بود، از Script Properties استفاده می‌کند.)

بقیه تنظیمات هم در همان بخش `CONFIG` است:

```js
FOLDER_ID: '',                       // آیدی پوشه مقصد؛ خالی = ریشه درایو
WEBHOOK_SECRET: 'change-this-...',   // یک رشته تصادفی طولانی
ALLOWED_USER_IDS: [],                // بعداً آیدی خودت را اضافه کن
SUBFOLDER_MODE: 'date',              // هر روز یک پوشه 2026-10-28
TEXT_MODE: 'doc',                    // متن‌ها سند گوگل
MAX_UPLOAD_MB: 19,
TIMEZONE: 'Asia/Tehran'
```

آیدی پوشه = آن تکه آخر آدرس پوشه درایو: `https://drive.google.com/drive/folders/`**`1AbCd...`**

### ۴. Deploy → Web app

**Deploy** (بالا راست) → **New deployment** → آیکن چرخ‌دنده → **Web app**:

| فیلد | مقدار |
|---|---|
| Description | `v1` |
| **Execute as** | **Me (your@gmail.com)** ← مهم: فایل باید با اکانت خودت در درایو برود |
| **Who has access** | **Anyone** ← مهم: تلگرام باید بتواند POST کند |

**Deploy** → لینک **Web app URL** را کپی کن (شبیه `https://script.google.com/macros/s/AKfy.../exec`).

اولین بار گوگل اجازه می‌خواهد:
**Authorize access** → اکانت خودت → «Google hasn't verified this app» → **Advanced** → **Go to Telegram→Drive (unsafe)** → **Allow**

این پیام عادی است چون اسکریپت را خودت نوشتی؛ دسترسی درایو و درخواست به تلگرام (`script.external_request`) را تأیید می‌کند.

**تست سریع قبل از ادامه:** بالای ادیتور، از منوی کشویی توابع **`checkSetup`** را انتخاب کن → **Run**. در **Execution log** باید ببینی:

```
✅ token OK → @T2GD2Tbot
✅ folder OK → My Drive | https://drive.google.com/...
webhook url → https://script.google.com/macros/s/.../exec
```

### ۵. اول وضعیت را ببین، بعد webhook را ست کن

**۵.۱ — چک وضعیت:** این آدرس را باز کن (SECRET = همان `WEBHOOK_SECRET`):

```
<WEB_APP_URL>?k=YOUR_SECRET
```

باید یک صفحه **متنی** ببینی (نه صفحه سفید)، شبیه:

```
=== 🤖 ربات تلگرام → گوگل درایو ===

آدرس این اسکریپت: https://script.google.com/macros/s/.../exec

✅ توکن: درست → @T2GD2Tbot
✅ پوشه مقصد: My Drive → https://drive.google.com/...
وضعیت webhook: {"ok":true,...}
```

اگر نوشت «🔑 توکن تلگرام تنظیم نشده» یعنی قدم ۳ انجام نشده یا New version دیپلوی نکرده‌ای.

**۵.۲ — ست کردن webhook:**

```
<WEB_APP_URL>?k=YOUR_SECRET&action=setup
```

باید ببینی:

```
✅ webhook ست شد
ربات: @T2GD2Tbot
webhook: https://script.google.com/macros/s/.../exec?k=YOUR_SECRET
نتیجه تلگرام: {"ok":true,...}
```

> چرا `?k=SECRET`؟ چون دسترسی Web app روی «Anyone» است؛ این سکرت جلوی آپلود غریبه‌ها را می‌گیرد. یک رشته طولانی و تصادفی بگذار.

### ۶. تست

در تلگرام به **@T2GD2Tbot** برو:
- `/start` → باید خوش‌آمد + لینک پوشه مقصد بیاید
- `/id` → آیدی عددی‌ات را بگیر و در `ALLOWED_USER_IDS` بگذار (Deploy دوباره → مرحله ۴/۵)
- یک متن، یک عکس، یک PDF، و یک آلبوم ۳ عکسی بفرست → هرکدام باید `✅ ذخیره شد` با لینک بدهند

## 🩺 اگر ربات جواب نمی‌دهد (سه آدرس جادویی)

همه اینها فقط با باز کردن یک آدرس در مرورگر انجام می‌شوند:

| آدرس | کار |
|---|---|
| `...?k=SECRET&action=diag` | گزارش کامل: توکن، پوشه، آدرس webhook، `last_error_message` تلگرام، و «آیا تا حالا آپدیتی رسیده؟» |
| `...?k=SECRET&action=replay` | پیام‌هایی که تلگرام هنوز تحویل نداده را **همین حالا پردازش می‌کند** (فایل‌ها ذخیره می‌شوند، جواب‌ها می‌آیند) و webhook را دوباره ست می‌کند |
| `...?k=SECRET&action=posttest` | به خودش یک POST می‌زند و کد پاسخ را نشان می‌دهد؛ **برای خطای 302** |
| `...?k=SECRET&action=sendtest&chat=CHAT_ID` | تست خروجی: یک پیام تست به آن چت می‌فرستد (آیدی چت را از @userinfobot بگیر) |

**تشخیص سریع بر اساس نتیجه `diag`:**

| چه می‌بینی | معنی | راه‌حل |
|---|---|---|
| `📥 هنوز هیچ آپدیتی از تلگرام نرسیده` | webhook تحویل نمی‌شود | *Who has access* را روی **Anyone** بگذار (نه «Anyone with Google account») و بعد `action=setup` |
| `last_error_message: Unauthorized` یا `Wrong response` | تلگرام به اسکریپت دسترسی ندارد | همان بالا + `action=setup` |
| `webhook url: (ست نشده!)` | `action=setup` اجرا نشده | `action=setup` |
| `⚠️ آدرس webhook با تنظیمات فعلی یکی نیست` | سکرت عوض شده ولی setup دوباره اجرا نشده | `action=setup` |
| `pending_update_count` بالای صفر | پیام‌ها معلق‌اند | `action=replay` |
| `❌ توکن: تلگرام قبول نکرد` | توکن غلط/revoke شده | توکن جدید در `BOT_TOKEN` + New version |
| همه سبز و webhook درست | کد رسیده ولی جواب نمی‌آید | در ادیتور **Executions** را ببین؛ اگر خطا داشت متنش را بفرست |

**⚠️ نکتهٔ `&amp;`:** اگر آدرس را از یک پیام/چت با `&amp;action=...` کپی کنی، آن پارامتر بی‌اثر می‌شود (کد جدید این را تحمل می‌کند، ولی بهتر است `&` خالی بنویسی). مطمئن‌ترین راه برای این تنظیمات، اجرای تابع از داخل ادیتور است.

**مهم‌ترین تنظیم:** اگر پیام‌ها به اسکریپت نمی‌رسند، تقریباً همیشه *Who has access* روی **Anyone with Google account** است. تلگرام که اکانت گوگل ندارد پس رد می‌شود. باید **Anyone** باشد.

## 🚧 خطای `Wrong response from the webhook: 302 Found`

این خطا یعنی **گوگل به تلگرام ریدایرکت (302) می‌دهد** و تلگرام ریدایرکت را دنبال نمی‌کند. پس پیام‌ها به اسکریپت نمی‌رسند و در صف می‌مانند (`pending_update_count`).

در مرورگر خودت صفحه باز می‌شود چون **کوکی لاگین گوگل** داری؛ تلگرام ندارد.

**علت ۹۹٪:** در تنظیمات دیپلوی، *Who has access* روی **Anyone with Google account** (یا Only myself) است.

### درست کردنش (۶۰ ثانیه)

1. **Deploy → Manage deployments** → روی ✏️ (مداد) دیپلوی فعال بزن
2. **Execute as:** `Me (your@gmail.com)`
3. **Who has access:** **`Anyone`** — بدون کلمهٔ Google، بدون «با اکانت گوگل»
4. **Version:** `New version` → **Deploy**
5. `...?k=SECRET&action=setup` را باز کن (webhook تازه ست می‌شود و خطای قبلی پاک می‌شود)
6. `...?k=SECRET&action=posttest` → باید بگوید `کد پاسخ: 200` و `✅ عالی`
7. `...?k=SECRET&action=replay` → همان پیام‌هایی که در صف مانده‌اند **همین حالا** ذخیره می‌شوند
8. `...?k=SECRET&action=diag` → باید `pending_update_count: 0` و `last_error_message: ندارد` باشد

> اگر `posttest` باز هم 302 داد، یک‌بار **New deployment** از صفر بساز (نه New version) و URL جدید را در `setup` استفاده کن؛ گاهی آدرس یک دیپلوی قدیمی گیر می‌کند.

## 🔄 حالت Polling — راه قطعی وقتی گوگل جواب 302 می‌دهد

اگر `action=posttest` هم `302` داد، یعنی گوگل به هر درخواست بیرونی ریدایرکت می‌دهد و **هر کاری با تنظیمات دیپلوی بکنی درست نمی‌شود** (مثلاً اکانت Workspace سازمانی که «Anyone» را ممنوع کرده، یا گیر کردن نسخهٔ دیپلوی).

راه‌حل: **webhook را کنار بگذار و خود Apps Script هر ۱ دقیقه از تلگرام بپرسد پیام جدیدی آمده یا نه.** به دسترسی عمومی هیچ نیازی ندارد؛ فقط یک تریگر زمانی.

### روشن کردن — ساده‌ترین راه (بدون URL)

**در ادیتور Apps Script:** بالای صفحه منوی کشویی توابع → **`setupPollingNow`** را انتخاب کن → **Run**.

> ⚠️ اگر در Execution log فقط `Execution started / completed` دیدی، یعنی تابع درستی اجرا نشده (احتمالاً روی گزینهٔ پیش‌فرض ماندی) یا نسخهٔ کدِ قبلی (چون کد جدید حتماً چند خط لاگ می‌نویسد). با تابع **`statusNow`** تست کن: باید حدود ۱۰ خط گزارش چاپ کند، از جمله `نسخه کد: polling-2026-10-28b`.

همین. سه کار با هم انجام می‌شود: حذف webhook، نصب تریگر هر ۱ دقیقه، و پردازش فوری پیام‌های معلق (همان استارت و فایل‌هایت). نتیجه را در **Execution log** می‌بینی:

```
webhook حذف شد: {"ok":true,...}
✅ تریگر هر ۱ دقیقه نصب شد.
اجرای فوری: 6 پیام پردازش شد.
```

> اگر پیام خطای اجازه داد، یک‌بار Authorize کن (همان صفحه‌ای که در قدم ۴ دیدی).

**تابع‌هایی که از ادیتور اجرا می‌شوند:** `statusNow()` گزارش کامل • `setupPollingNow()` روشن کردن • `pollOnce()` یک دور فوری • `stopPollingNow()` برگشت به webhook • `checkSetup()` تست توکن/پوشه.

### یا از طریق آدرس



این آدرس را باز کن:

```
<WEB_APP_URL>?k=SECRET&action=startpolling
```

چه می‌کند:
1. webhook را حذف می‌کند (وگرنه `getUpdates` خطای 409 می‌دهد)
2. تریگر **هر ۱ دقیقه** برای تابع `pollOnce` نصب می‌کند
3. همین حالا یک اجرا می‌زند → پیام‌های معلق (همان فایل و استارتت) ذخیره می‌شوند

> بدون نیاز به آدرس عمومی؛ از این به بعد هر پیام حداکثر ~۱ دقیقه بعد پردازش می‌شود.

### آدرس‌های مربوطه

| آدرس | کار |
|---|---|
| `&action=startpolling` | روشن کردن polling (webhook را حذف می‌کند) |
| `&action=pollnow` | یک اجرای فوری (بدون منتظر دقیقه ماندن) + گزارش وضعیت |
| `&action=stoppolling` | خاموش کردن polling و برگشت به webhook |
| `&action=diag` | خط «🔄 حالت Polling فعال است» یا «فعال نیست» + **نسخه کد** را نشان می‌دهد |
| تابع `setupPollingNow` در ادیتور | همان کار `startpolling` بدون نیاز به URL (توصیه‌شده) |
| تابع `stopPollingNow` در ادیتور | خاموش کردن polling بدون URL |

**محدودیت‌ها:** تأخیر تا ~۱ دقیقه؛ روزانه ۹۰ دقیقه زمان اجرا برای اکانت Gmail (با اجراهای چند ثانیه‌ای، عملاً کافی است)؛ هر اجرا حداکثر ۲۰ پیام.

### کدام حالت را انتخاب کنم؟

| وضعیت | حالت |
|---|---|
| `action=posttest` → `کد پاسخ: 200` | webhook (سریع‌تر، بدون تأخیر) |
| `action=posttest` → `302` یا `401` | ✅ **polling** |
| اکانت Gmail شخصی معمولی | webhook معمولاً کار می‌کند |
| اکانت Google Workspace (سازمانی) | اغلب polling لازم است |

## 🧰 چیزهایی که باید بدانی

**بعد از هر تغییر کد، Deploy لازم است:**
Deploy → **Manage deployments** → مداد ✏️ → Version: **New version** → Deploy.
(اگر فقط ذخیره کنی، نسخه قبلی همان‌طور اجرا می‌شود.)

**نسخهٔ کد:** در صفحهٔ وضعیت (`action=diag` یا آدرس اصلی) خطی به اسم «نسخه کد» هست. اگر آن را نمی‌بینی، یعنی نسخهٔ قدیمی کد دیپلوی/ذخیره شده است (Ctrl+S و New version را دوباره انجام بده).

**دستورهای ربات:** `/start` `/help` `/id` `/folder` `/ping`

**دو حالت کار:** webhook (بدون تأخیر) یا polling با تریگر ۱ دقیقه‌ای (اگر گوگل 302 بدهد).

**چه چیزهایی ذخیره می‌شوند:** متن (Google Doc)، عکس، فایل، ویدیو، گیف، موزیک، ویس، ویدیو-نوت، استیکر. آلبوم چند عکسی → همه ذخیره، یک پیام جمع‌بندی.

**سهمیه‌ها (حساب Gmail معمولی، روزانه):**

| مورد | سقف |
|---|---|
| تماس‌های UrlFetch (≈ هر فایل ۲ تماس) | ۲۰٬۰۰۰ در روز |
| زمان اجرا | ۹۰ دقیقه در روز |
| هر اجرا | حداکثر ۶ دقیقه |
| حجم هر فایل | ۱۹MB (سقف خود Bot API تلگرام) |

یعنی روزی چند هزار فایل کوچک مشکلی ندارد؛ اگر بیشتر شد، باید سراغ سرور/VPS بروی.

**اگر خواستی از VPS استفاده کنی:** همان `bot.py` در پوشه بالاست، ولی به Cloud Console نیاز دارد که برای تو بسته است — پس فعلاً همین Apps Script بهترین گزینه است.

## 🩺 عیب‌یابی

| علامت | علت / راه‌حل |
|---|---|
| ربات جواب نمی‌دهد | `?k=SECRET&action=info` را باز کن و `pending_update_count` و `last_error_message` را ببین. اگر `last_error` هست، Deploy با دسترسی **Anyone** را چک کن |
| `❌ توکن ربات درست نیست` | مقدار `BOT_TOKEN` در Script Properties غلط/قدیمی است (توکن revoke‌شده) |
| پیام می‌آید ولی فایل ذخیره نمی‌شود | Executions (ستون چپ) → آخرین اجرا → لاگ خطا |
| `Authorization required` در لاگ | مرحله ۴ را دوباره انجام بده و Allow کن |
| `⚠️ پوشه مقصد پیدا نشد` | `FOLDER_ID` غلط است یا با این اکانت دسترسی ندارد |
| `⚠️ سهمیه روزانه … پر شد` | فردا ادامه می‌دهد؛ یا حجم آپلود را کمتر کن |
| **صفحه سفید** هنگام باز کردن آدرس | ۱) آدرس باید کامل باشد: `.../exec?k=YOUR_SECRET` (بدون `?k=` صفحه پیام «دسترسی ندارید» می‌دهد). ۲) مطمئن شو آدرس **Deployment** را باز می‌کنی نه آدرس ادیتور (`/edit`). ۳) در Manage deployments چک کن *Who has access = Anyone* و *Execute as = Me*. ۴) بعد از هر تغییر کد، **New version** دیپلوی کن. ۵) اگر باز سفید بود، از منوی توابع `checkSetup` را Run کن و متن Execution log را بفرست |
| `SyntaxError: Invalid or unexpected token line: 1` | کد ناقص/آلوده کپی شده. Ctrl+A → Delete → کل [`Code.template.gs`](Code.ascii.gs) را بچسبان (بدون هیچ متن اضافه‌ای در خط اول) |
| `Unexpected identifier` یا خطای عجیب در خطی که متن فارسی دارد | نسخه ASCII را استفاده کن؛ کاراکترهای راست‌به‌چپ در کپی/پیست خراب می‌شوند |
| بعد از تغییر کد اثری ندید | باید **New version** در Manage deployments بزنی |
| اجرا با `Exceeded maximum execution time` قطع شد | فایل خیلی بزرگ/کند بود؛ `MAX_UPLOAD_MB` را کمتر کن |
| خطای `Conflict: can't use getUpdates method while webhook is active` | یعنی جای دیگری `bot.py` با همین توکن در حال اجراست؛ آن را ببند (این اسکریپت webhook استفاده می‌کند) |

## ❓ اگر خود script.google.com هم بن بود

لینک `script.google.com` را باز کن و یک پروژه خالی بساز؛ اگر همان پیام «خدمات در دسترس نیست» را دیدی، Apps Script هم بسته است. در این حالت دو راه می‌ماند:

1. **اکانت گوگل دیگری** (کاری/دوم) که با این محدودیت مواجه نیست — کد و مراحل عیناً همان است.
2. **عوض کردن مقصد فایل**: به‌جای گوگل درایو، روی S3/Cloudflare R2/Nextcloud یا حتی چت «Saved Messages» خودت ذخیره کنیم. بگو تا نسخه‌اش را بسازم.
